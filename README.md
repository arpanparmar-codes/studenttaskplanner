Student Task Planner 📚

Student Task Planner is an Android application developed to help students manage their academic tasks and assignments. It allows students to add tasks, select due dates, view tasks, search for a task using its ID, mark tasks as completed, and delete tasks.

✨ Features

- Add Tasks: Create tasks with a title, notes, and due date.
- Choose Due Date: Select a date for your task.
- View Tasks:** Display saved tasks.
- Search Tasks by ID: Find a specific task using its ID.
- Mark Tasks as Completed: Track completed tasks.
- Delete Tasks: Remove tasks that are no longer needed.
- Local Data Storage: Store task information using SQLite.

🛠️ Technologies Used

- Programming Language: Java
- Development Environment: Android Studio
- User Interface:** XML
- Database:** SQLite
- Platform:** Android

📱 Application Screens

The application includes a main screen for managing tasks and a separate screen for searching tasks by ID.

🗄️ Database

The application uses SQLite to store task information locally on the device.


🚀 How to Run

1. Clone or download this repository.
2. Open Android Studio.
3. Select Open and choose the downloaded project folder.
4. Allow Gradle to sync.
5. Connect an Android device or start an emulator.
6. Click Run to launch the application.

🎯 Project Objective

The objective of this project is to develop a simple Android application that helps students organize academic tasks and assignments while learning Android development, Java programming, XML layouts, and SQLite database operations.
